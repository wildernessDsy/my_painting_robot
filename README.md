# Painting Robot

This is a painting robot project for the 2026 IPP.

## Setup

Clone the repo to local using git:

```bash
git clone https://github.com/wildernessDsy/my_painting_robot.git
```

Then open your Unity Hub, go to "Projects" on the left:
- If you don't have any projects currently, click "Import projects" and select the folder you just cloned.
- If you have some projects added, click "Add" then "Add project from disk", and select the folder you just cloned.

## Test Run

Click the triangle "Play" button to run the simulation. Pressing `F` to enter inspect mode.
